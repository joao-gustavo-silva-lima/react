# DevLinks Dashboard

Welcome to my personal dashboard project for organizing and tracking links efficiently. This repository focuses on building a modern, type-safe interface for managing useful resources, tools, and references using React, TypeScript, Vite, and Tailwind CSS.

## 🚀 Repository Overview

The app is designed to help users keep a curated list of links with category organization, search/filter capabilities, click tracking, and quick access actions. It combines a clean interface with lightweight API integration and strong validation rules for data integrity.

## 🔑 Core Files

When exploring this project, these are the main files to inspect:

1. 🧩 **`src/App.tsx`**: Composes the dashboard layout, state, modal behavior, and link management flow.
2. 📚 **`src/components/LinkList.tsx`**: Contains the card list, click-through logic, delete actions, category tags, and loading/error states.
3. 🧠 **`src/types/links.types.ts`**: Defines the data shape for links and validates user input with `zod`.
4. 🌐 **`src/api/links.api.ts`**: Handles all HTTP calls to the backend API for fetching and mutating links.

## ✨ Features

- Link registration and editing through a modal form
- Search and filtering by title, category, and tag
- Click tracking and redirect actions
- Metrics cards for total links, total clicks, and popular category
- Type-safe validation for URLs, categories, and tags
- Responsive UI styled with Tailwind CSS
- Clean React component structure with reusable hooks

## 🛠️ Getting Started

To run the project locally, make sure you have **Node.js** installed.

### 1. Clone the repository

```bash
git clone https://github.com/joao-gustavo-silva-lima/react.git
cd react/devlinks-dashboard
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

This will launch the application in development mode, usually at:

```text
http://localhost:5173
```

### 4. Build for production

```bash
npm run build
```

### 5. Lint the project

```bash
npm run lint
```
